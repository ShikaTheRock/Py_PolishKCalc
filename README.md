# Py Polish KCalc

Simple calculator made with **Python** and **Tkinter**, based on an old Bash calculator.

## Features

* Basic operations: `+`, `-`, `*`, `/`
* Decimal numbers
* Calculation history
* Clear and backspace buttons
* Simple GUI

## Requirements

* Python 3
* Tkinter

## Run

Clone the repository:

```bash
git clone https://github.com/ShikaTheRock/Py_PolishKCalc.git
cd Py_PolishKCalc
```

Run the calculator:

```bash
python3 PythonPolishKCalcGUI.py
```
